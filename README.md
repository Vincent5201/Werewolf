# A werewolf game
https://warewolf.onrender.com

## Implemented Features
* Core game flow, including night phase, day discussion, day voting, and last words.
* Abilities for the following roles:
* Seer, Witch, Hunter, Guard, Idiot, Wolf King, Werewolf
* Sheriff system, including elections, determining speech order, and the Sheriff’s Badge.
* Room system, allowing players to join/host via web browser using specific room IDs.
* Customization for the number of each role in a game.
* Text-based logs of the entire game process.

## Note

* This is a personal practice project, developed with the assistance of LLMs.

# 狼人殺
https://warewolf.onrender.com

## 現有功能
* 核心遊戲進程，包含夜晚階段、白天討論階段、白天投票階段、遺言階段等。
* 以下所列各角色的技能實作：預言家、女巫、獵人、守衛、白癡、狼王、狼人
* 警長系統，包含警長競選、指定發言順序、移交警徽等功能。
* 房間系統，支援玩家透過網頁連線開房、設置房號。
* 支援自由調整各角色的配置數量。
* 遊戲過程的文字化紀錄。

## 待開發項目
* 發言時間限制
* 語音對話功能
* 狼人自爆機制
* 更多角色擴充
* UI 視覺設計

## 備註
* 目前限制：防呆機制尚未完善，玩家需依照正常流程進行操作，否則可能會發生執行錯誤。
* 本專案為個人練習作品，開發過程中使用大型語言模型 (LLM) 輔助製作。
